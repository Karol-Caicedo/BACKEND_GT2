# BACKEND_GT2

API SIGICE (NestJS + PostgreSQL + TypeORM).

## Documentación de la API

- Swagger UI: `http://localhost:3000/api/docs` (usa el `PORT` configurado).
- OpenAPI JSON: `http://localhost:3000/api/docs-json`.
- Rutas cortas: `/docs`, `/api-docs` y `/api` redirigen a `/api/docs`; la raíz también redirige cuando no se sirve el frontend.
- Se desactiva con `ENABLE_SWAGGER=false`.

Consulta `AGENTS.md` para comandos, configuración y variables de entorno.
